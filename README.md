# astrbot_plugin_feiyu_qzone

让 bot 管理自己的 QQ 资料与空间：改昵称、改签名、改性别、发说说、删说说。

## 人格设定里要写什么（装了之后必看）

这个插件**不直接提供给模型的工具**，它把自己的动作注册进
[`astrbot_plugin_persona_mind`](../astrbot_plugin_persona_mind) 的 `feiyu` 入口。所以：

1. **必须同时装 `persona_mind`。** 只装本插件时，模型那边一个动作都看不到 —— 不是坏了，是没有入口。
2. **人格设定里只写「什么时候该动手」，不要写 `feiyu(...)`、`action=`、`target=` 或任何参数名。**
   参数格式由插件在真要动手的那一轮临时告诉她（`engine/specs.py` + `engine/selector.py`），
   写进人格只会变成「同一件事两处说法」，而且插件启停时人格不会跟着变。
3. 人格里有这么几行，本插件才会被自然调用：

- 「改个昵称叫…」「签名改成…」「性别改成…」「发条说说…」→ **改昵称 / 改签名 / 改性别 / 发说说**
- 只有主人（管理员）开口才会动
- 本插件被禁用时，这四条动作自动从人格与工具说明里消失，不用手工改

### 可以直接粘贴的一段

只装本插件时，把下面这几行加进人格设定的末尾就够了：

```
- 改昵称、改签名、改性别、发说说 → 只有主人开口才动
```

**不要**改成 `feiyu(action="...")` 那种写法——参数格式由插件在真要动手的那一轮临时给她。

**反例**（这些不该触发）：裸的「说说」、「评论区」单独出现、她说「我去看看」但没给具体目标。

完整的原理、可逐字复制的人格段落、写入脚本，见 [persona_mind/README.md](../astrbot_plugin_persona_mind/README.md#让她自然地用这些本事人格设定里要写什么)。


## 怎么用

| 你这么说 | 她做什么 |
| --- | --- |
| 「把签名改成 XXX」 | 改个性签名 |
| 「昵称改成 XXX」 | 改 QQ 昵称 |
| 「发条说说：今天……（仅自己可见）」 | 发说说，可见范围从正文里认 |
| 「你账号现在是谁」 | 报当前登录账号 |

**指令形式**：`/账号信息`、`/改昵称 <新名字>`、`/改签名 <内容>`、`/改性别 男/女`、`/发说说 [-p 64] <正文>`、`/删说说 <tid>`

**注意**：全部是**管理员动作**，非主人一律拒绝；说说发出去不可撤回。

## 特性

- **不碰密码**：全部走 NapCat 的扩展 action，不需要 QQ 密码与 cookie
- **权限可控**：写操作限定管理员，普通群友只能看 `/账号信息`
- **可见范围**：发说说支持 `-p <权限>`（1 公开 / 4 好友 / 64 仅自己）
- **模型可调用**：改资料走 `llm_tool`，聊天里说「把签名改成 xxx」就能改

## 安装

1. 确保 NapCat 已登录且 AstrBot 的 QQ 适配器在线
2. 目录放到 `astrbot/data/plugins/`，无第三方依赖
3. 重启 AstrBot

## 指令

| 指令 | 说明 |
| --- | --- |
| `/账号信息` | 看当前登录账号 |
| `/改昵称 <新名字>` | 改昵称（管理员） |
| `/改签名 <内容>` | 改个性签名（管理员） |
| `/改性别 男/女` | 改性别（管理员） |
| `/发说说 [-p 64] <正文>` | 发说说（管理员） |
| `/删说说 <tid>` | 删说说（管理员） |

## LLM 工具

`change_qq_nickname`、`change_qq_signature`、`change_qq_gender`、`post_qzone_moment`。

## 常见问题

**报 action 不支持**
NapCat 版本太旧或不支持对应扩展。升级 NapCat 后重试。

**发说说权限参数不生效**
不同 NapCat 版本字段名略有差异，看日志里实际返回体。
